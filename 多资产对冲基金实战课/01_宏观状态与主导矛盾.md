# 01｜宏观状态与主导矛盾

> 状态：第1章 1—6讲已完成。

## 第1讲｜怎样识别市场正在交易增长、通胀还是流动性

核心不是判断“经济现在是什么”，而是判断**市场正在为什么变化重新定价**。

把资产价格变化拆成几个主要冲击：

[
\Delta P_i \approx \beta_{i,G}\epsilon_G + \beta_{i,\pi}\epsilon_{\pi} + \beta_{i,L}\epsilon_L + \varepsilon_i
]

其中增长、通胀/政策、流动性冲击都可能同时存在。实战上不要单看“债券涨”或“股票跌”，而要做跨资产解释竞争：

- 2Y/10Y收益率
- 实际利率与盈亏平衡通胀
- 股票内部结构
- HY信用利差
- 铜、原油、美元、黄金

重要原则：**哪个假设能用最少额外解释，同时解释最多资产的变化？**

但不能把跨资产确认变成入场许可证。更合理的流程是：

**先提出假设 → 用有限风险下注 → 后续价格与基本面更新假设。**

## 第2讲｜复苏、再通胀和过热的分界

三个状态的核心差异不是绝对CPI，而是**新增需求最终转化成产量还是价格**。

- Recovery（复苏）：仍有大量闲置资源，新增需求更多转化为产出和就业。
- Reflation（再通胀）：名义增长恢复，价格回升但政策仍然容忍。
- Overheating（过热）：资源约束开始明显，新增需求更多转化成工资、价格和政策收紧。

真正的交易分界：

[
盈利改善收益 \quad vs \quad 政策和折现率成本
]

观察重点：
- 2Y政策路径
- 2s10s曲线
- 10Y实际利率
- 工资与职位空缺
- 通胀广度与持续性

典型状态迁移：

[
Reflation \rightarrow Policy\ Constraint
]

不是等第一次加息以后才确认，而是观察央行Reaction Function（反应函数）何时先改变。

## 第3讲｜软着陆与需求型衰退

同样的通胀回落可能来自两套机制：

[
Supply\ Improvement \rightarrow Inflation\downarrow
]

或

[
Demand\ Destruction \rightarrow Inflation\downarrow
]

Soft Landing（软着陆）的关键不是“降息”，而是：

[
Inflation\downarrow + Earnings\ Resilient + Credit\ Stable
]

需求型衰退则会同时出现：

[
Earnings\downarrow + Credit\ Spread\uparrow
]

因此降息并不自动利好股票。

实战重点不是只看CPI，而是看“去通胀损伤”：
- 就业动量
- 信用利差
- EPS修订
- 企业指引
- 通胀下降来自供给还是需求

核心问题：**这场去通胀到底花了多少经济增长？**

## 第4讲｜滞胀与供给冲击

同样的油价上涨，需要先区分：

[
Demand\ Reflation
]

和

[
Negative\ Supply\ Shock
]

供给冲击本质上是一场收入重新分配：

[
Consumers / Energy\ Importers \rightarrow Energy\ Producers / Exporters
]

随后通过实际收入下降、利润压缩和政策反应形成二阶传导。

真正危险的是：

[
Growth\downarrow + Inflation\uparrow + Policy\ Tightening\uparrow
]

这会破坏传统股债对冲。

实战上不要只看油价，要看：
- 原油期限结构
- 铜与油是否背离
- 实际收入
- 信用利差
- Breakeven与Real Yield组合
- 能源企业与下游行业利润重分配

## 第5讲｜为什么增长×通胀四象限经常失灵

四象限只告诉你结果：

[
Growth \times Inflation
]

但真正决定下一步资产走势的是驱动力。

升级后的状态模型：

[
State=\{G,\pi,M,F,C,S,FCI\}
]

其中：
- G：增长
- π：通胀
- M：货币政策
- F：财政
- C：信用
- S：供给/生产率
- FCI：金融条件

分析顺序：

**冲击来源 → 增长/通胀结果 → 市场价格**

而不是直接把“Goldilocks”机械映射成“股债双牛”。

例如增长强、通胀降，可能来自：
- 供应链改善
- 财政支持
- 生产率提升
- 市场金融条件放松

不同驱动下，长债、成长股、美元的方向可能完全不同。

## 第6讲｜综合演练：宏观状态卡

宏观状态卡不是“所有资产方向预测器”，而是共同风险地图。

建议固定记录：

### 1. 当前状态
- Growth
- Inflation
- Labor
- Monetary
- Fiscal
- Credit
- Supply/Productivity
- Financial Conditions

### 2. 三套竞争情景
- Base Case
- Bull Case
- Bear Case

每个情景必须写：
- 未来会发生什么
- 哪些数据支持
- 哪些价格会先反应
- 什么条件证伪
- 时间窗口

### 3. 交易映射

一笔交易必须单独回答：
- 我真正下注的变量是什么？
- 当前宏观状态是顺风还是逆风？
- 为什么选择这个表达？
- 什么信息让我减仓/退出？

最终框架：

[
Shock
\rightarrow Growth/Inflation
\rightarrow Policy\ Reaction
\rightarrow Financial\ Conditions
\rightarrow Asset\ Pricing
]

而交易流程应反过来：

**寻找潜在错价 → 提出未来变化假设 → 有限风险下注 → 后续验证/证伪。**
