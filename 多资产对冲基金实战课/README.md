# 多资产对冲基金实战课

目标：把宏观假设转化为能验证、能表达、能控制风险、能复盘的多资产交易与组合框架。

课程主线：

**宏观状态 → 跨资产传导 → 市场预期 → 叙事 → 仓位与资金流 → 估值与相对价值 → 交易表达 → 组合构建 → 风险管理 → 交易执行 → 系统化研究**
